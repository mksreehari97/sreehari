OVERVIEW

The Bubble Game is an interactive, underwater survival game built entirely from scratch using fundamental web technologies: HTML5, CSS3, and Vanilla JavaScript. The project was designed as a technical exercise to build a robust game loop, manage moving objects, and deliver a smooth user experience without relying on external game engines or frameworks.

The mechanics require focus and reflexes: the player controls a red fish navigating an aquatic environment. The objective is to collect as many rising bubbles as possible, with each bubble granting 1 point. However, the player must actively dodge randomly generated yellow enemy fish—a single collision triggers an immediate Game Over.

DEVELOPMENT & LOGIC

Building a 2D game in Vanilla JavaScript requires meticulous attention to the DOM, position tracking, and continuous rendering. I architected the game to ensure high performance while managing multiple moving elements simultaneously.

  • Collision Detection: Developed custom JavaScript logic to constantly calculate the intersecting coordinates between the player (red fish), enemies (yellow fish), and collectibles (bubbles) to accurately trigger scoring or game-over states.
  • The Game Loop: Implemented a fluid, continuous loop that updates the positions of the floating bubbles and swimming enemies on every frame, ensuring smooth movement across the screen.
  • State Management: Variables like the current score, enemy spawn rates, and active game status are managed dynamically through JavaScript, instantly reflecting changes on the UI.

UI & ASSETS

To make the game visually engaging, I utilized clean 2D graphical assets layered over a vibrant, stylized ocean background. CSS3 was combined with JavaScript-driven coordinate updates to bring the environment to life.

The interface was kept intentionally minimalist, placing the score counter neatly in the top corner and ensuring the core survival mechanics remained the absolute focus for the player.
