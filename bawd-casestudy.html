OVERVIEW

BAWD is a modern fashion e-commerce platform designed to provide a seamless online shopping experience for users while offering robust management tools for the business.

The project encompassed building a highly interactive customer-facing storefront and a secure, feature-rich Admin Dashboard. The entire platform was engineered from the ground up using the MERN stack (MongoDB, Express.js, React.js, Node.js) to ensure scalability, fast data flow, and a smooth user interface.

OBJECTIVE & ROLE

As the primary full-stack developer, my objective was to architect a comprehensive 3-tier application that handled everything from product discovery to secure payment processing and inventory management.

My Contributions:

  • Developing the interactive frontend storefront using React.js.
  • Architecting the backend API using Express.js and Node.js.
  • Designing and managing the database schema with MongoDB.
  • Integrating Stripe for secure, frictionless checkout and payment processing.
  • Building a comprehensive Admin Dashboard using Material UI for data visualization and management.

WHY THE MERN STACK?

MERN is a full-stack solution following the traditional 3-tier architectural pattern: the front-end display tier (React.js), the application tier (Express.js and Node.js), and the database tier (MongoDB).

Database Tier: MongoDB was designed to store JSON data natively using a binary version called BSON. Everything from its command-line interface to its query language (MQL) is built on JSON and JavaScript. It pairs perfectly with Node.js, making the storage, manipulation, and representation of JSON data incredibly efficient.

Application & Display Tiers: Express.js wraps HTTP requests and responses, making it easy to map URLs to server-side functions. React.js handles the frontend, building interactive HTML user interfaces that communicate smoothly with the server. This combination ensures JSON data flows naturally from front to back, resulting in a fast, cohesive, and easily debuggable application.

ADMIN DASHBOARD & PAYMENTS

To give the business full control over the platform, I developed a dedicated Admin Dashboard alongside the main storefront. The dashboard allows administrators to easily view store analytics, manage user accounts, and create or edit product listings.

For a clean, professional aesthetic, I utilized Material UI to design the dashboard's data tables, forms, and icons. Finally, the platform's financial transactions were secured by integrating the Stripe API, handling end-to-end payment processing directly within the custom checkout flow.
